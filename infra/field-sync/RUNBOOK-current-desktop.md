# Archived Field Sync Runbook

This file is retained only to record that a desktop-specific field runbook
previously existed here. Its machine-specific container names, credentials,
snapshot filenames, package paths, and commands are intentionally not retained
because they are not valid general project instructions.

Do not use this file as an environment-value source or as an executable SOP.
For a new field synchronization session, start with
[Field Sync README](README.md), inspect the current environment using its
already approved values, and create a new untracked session-specific runbook.
Environment values must not be copied, inferred, or changed from an older field
session.
